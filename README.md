# Navadurga and the 51 Shakti Peethas
Static English website: nine forms of Durga (legend, vehicle, chakra, mantra, dhyana shloka) and a searchable, filterable guide to 51 Shakti Peethas.

Run: open `index.html`. Deploy: GitHub Pages from `main` / root.
Files: `index.html`, `style.css`, `script.js`, `data.js` (all content; edit here).

Note: peetha lists differ between texts (4, 18, 51). This follows the common Tantra Chudamani-style list; verify locations with trusted sources before travel and open a PR with citations to correct any entry.
